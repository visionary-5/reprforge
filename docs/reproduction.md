# Reproduction

Use Linux, Python 3.11, an NVIDIA A100 80 GB, CUDA 12.4 and BF16 for the paper
configuration. CPU library tests require Python 3.10+. Select an available GPU;
all generated inputs and outputs belong outside the checkout.

## Install

```bash
python -m pip install -e '.[dev]'
python -m pytest -q
python examples/basic_replay.py
python -m pip install -r experiments/requirements-gpu.txt
```

## Prepare public inputs

```bash
python experiments/reconstruction/prepare_inputs.py --root /data/reprforge-inputs
```

The preparation script downloads models and datasets from a versioned source list, verifies
SHA-256 content hashes, and writes `endpoint-config.json` with local absolute paths.
Use `--resume` after an interrupted download or `--check-only` for offline
verification. `configs/colqwen.json` documents the configuration schema.
No historical experiment output is needed. Four small retrieval-projection
inputs are shipped under `configs/projections/`; `sources.json` records their
origin and content hashes.

## Reproduce independent reconstruction

```bash
CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=8 \
  python experiments/reconstruction/run.py \
  --config /data/reprforge-inputs/endpoint-config.json \
  --output /data/reprforge-reconstruction
python experiments/reconstruction/verify_tensor_payloads.py \
  --output-root /data/reprforge-reconstruction --report /data/reprforge-bits.json
```

Use a new output directory. The source process persists visual states and exits.
Each target starts independently, encodes the raw pages, reloads the source
states, and compares representations and ordered retrieval results. The verifier
checks the tensor banks generated by your run.

## Additional experiments

The [experiment index](../experiments/README.md) links quality, compression,
state-design ablation and adapter inspection. Each directory provides its own
input contract and commands. Compare results only within matching datasets,
processor budgets and reference paths.

## Timing and correctness

- Reconstruction timing includes raw image decoding and processing, or warm
  state reads, plus model execution and transfers. It excludes model loading,
  initial state retention, scoring, output serialization and ANN construction.
- The default reconstruction protocol uses one warmup per route followed by a
  paired pass. Use `reconstruction/full_collection/repeat_timing.py` with its
  repeat protocol for repeated measurements; page variation is not run variance.
- Quality experiments use a shared visual-prefix reference. Independent native
  raw reconstruction is checked separately.
- Compression stage timing excludes persistent state IO. Report storage and
  fidelity separately; similar quality does not establish exact reconstruction.
- Proactive state retention and retrofit acquisition have different costs.
  Measure initial retention, transfers, serialization and writes separately
  when estimating deployment cost.
