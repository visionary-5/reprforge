# 历史反馈物化 v2：证据复用存在，但“历史相关”不是视觉收益信号

日期：2026-08-06  
冻结提交：`395a800`  
判定：**历史反馈策略 gate 失败；保留部分物化问题，停止把页面相关性/热度当作方法**

## 实验边界

五折交叉时间代理中，每一折只把其余四折视为历史。`history_relevance` 只能读取历史 qrel，
将其解释为过去的点击或成功答案反馈；未来 qrel 和未来视觉分数仅用于评测。融合仍分别报告
不可部署的全局视觉标定 oracle 与朴素子索引融合，避免把选择问题和分数校准混在一起。

## 正确证据是否会复用

| 领域 | 未来唯一相关页曾在历史出现 | 未来相关页事件曾在历史出现 |
|---|---:|---:|
| HR | 78.9% | 82.4% |
| Finance | 58.0% | 62.4% |
| IRPAPERS | 0.0% | 0.0% |

HR 和 Finance 确实具备持久物化可摊销的 workload 结构；IRPAPERS 没有。因此先前依据
BM25 Top-20 得到的 70%--86% “复用”不能代替正确证据复用。对 IRPAPERS，查询时非持久
视觉分析比依赖历史 gold promotion 更合理。

## 历史反馈策略

下表使用全局 z-score oracle 标定，只隔离页面选择的迁移能力。数值为相对完整 z-score
hybrid 的 Gain Recovery；负数表示比 text-only 更差。

| 领域 | 历史候选频率 20% / 40% | 历史相关反馈 20% / 40% | 标签 oracle 20% |
|---|---:|---:|---:|
| HR | -60.9% / -5.6% | -9.1% / **71.7%** | 198.4% |
| Finance | -124.7% / -58.5% | -66.1% / **-44.5%** | 239.4% |
| IRPAPERS | 91.5% / 97.6% | 90.2% / 97.2% | 507.2% |

预先写入协议的通过条件是：20% 或 40% 预算下，历史反馈在两个具有正 Full-hybrid 增益的
领域恢复至少 50% 增益。只有 HR 40% 通过，Finance 失败，所以总体 **NO-GO**。
IRPAPERS 的 RRF Full-hybrid 增益为负，且 gold 复用为零；其 z-score 数字不能用于证明
持久 gold promotion，而主要来自候选频率填充和融合差异。

加入 25% 文本风险覆盖没有改善结果：HR 40% 的 Gain Recovery 从 71.7% 降为 28.5%，
Finance 从 -44.5% 降为 -64.3%。当前以文本 posting bytes/低候选可见性定义的
`S_cover` 不是有效视觉风险度量。

## 失败原因

页面曾经相关，只说明它回答过问题；它没有说明视觉表示相对文本表示能修正未来排序。
将所有历史相关页接入视觉通道，会让很多“文本已经足够”的页面产生额外视觉噪声。
因此需要学习或估计的是页面的**边际视觉检索收益**，而不是相关性、热度或候选频率。

当前结果把方法核心进一步收敛为两项，二者都尚未解决：

1. `S_benefit`：只根据历史中可观察的文本失败、视觉修复和重复主题，估计未来边际视觉收益；
2. `S_cover`：在没有历史命中的视觉长尾上，用真正的 OCR/布局/页面类型信号维持覆盖。

## 下一步 gate

只再做一次短周期、可证伪实验：模拟页面在历史查询中被按需解析后，记录其可观察的
文本失败/视觉修复反馈，用历史边际收益选择未来持久页面；同时将历史从随机 query fold
升级为按文档/主题或时间排列的 trace。若在 HR/Finance 的 20%--40% 预算下仍不能稳定
优于历史相关和候选频率，则现有 benchmark 无法支撑在线持久物化方法，应转向真实 trace
或只保留离线预算物化 claim。此 gate 通过前不上 GPU，也不做缓存或延迟优化。
